# Blast Media Mockup Builder — V1.1

A standalone GitHub Pages-ready web app for production proof PDFs.

## Deploy to GitHub Pages
1. Create a **new** GitHub repository (keep the Rinkboard Builder repository untouched).
2. Upload **index.html**, **styles.css**, **app.js**, and the **assets** folder to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and Save.
4. Open the published Pages URL after deployment.

## Use
Drag and drop PDF artwork or click the upload area. Choose Separate or Combined, enter production details, and export PDF. The app does not connect to Dropbox or upload your artwork to a server. PDF.js and jsPDF are loaded from CDN, so an internet connection is required.
